# Smart Study Planner 📚

A Python project designed to help students organize their studies and plan their learning.

## About the Project

Smart Study Planner is a beginner-friendly Python project that I am developing to make study planning easier. The goal is to build a program that helps students organize subjects and chapters, identify priorities, and create a useful study schedule.

## Current Features

- Collects the student's name
- Takes the subject and chapter as input
- Records the difficulty level of a chapter
- Displays the entered study information

## Technologies Used

- Python
- Git
- GitHub

## Planned Features

- Automatically prioritize chapters
- Set exam dates and deadlines
- Allocate study time
- Generate a daily study plan
- Track completed chapters and progress
- Save study data

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

   `python main.py`
